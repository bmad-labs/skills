2. Purpose

The design documents are read as instructions by three readers:

  • the builder Agent, which decides what to implement and what to leave alone;
  • the Delivery Manager, which plans the next Story;
  • the tests, which check what a sentence promises.

A wrong sentence causes one of two faults.

FaultConsequenceExample in this batch
A sentence describes work that is not done The reader checks for an output that does not exist. A later builder assumes the work is present, so it is omitted or duplicated. The sync note claimed it marks finished setup work as done and lists Stories affected by a Blueprint change. It does neither.
A sentence omits a fact that is needed The reader has no answer and must infer one. Two readers can infer differently. No document stated where a Story's status is read from, so the rule "wait until earlier Stories are done" had no input.

3.2 A claim records the commit the Story starts from your decision clauses 14, 15

Current
The claim record holds the Lab name only. At the end of a build the runner must compare the final commit with the commit the Story started from, and no record holds that commit.

The claim also records the origin/staging commit the worktree starts from. The runner can then name the commits and files that belong to the Story.

The build result cannot be read without a start point, and a Story cannot move to validation without that result. The change adds one value to each claim.

3.4 A session that attempted a hidden-test read is not resumed your decision clauses 7, 16

Current
The guard denies the read and writes an alert. No record marks the session, so the next restart resumes it.
After
The denial also sets a yes/no mark on the session record. The next restart refuses to resume that session for any Role except the App Validator and starts a new one.
Reason
The rule "a conversation that saw hidden tests is never resumed" has no record to read, so it cannot be enforced or tested. Story 4.6 needs the mark for its test.

8. Decisions

  1. decision Apply the nine proposed clauses? All nine, the six that block a Story, or none.
  2. decision Lab chat. May the Delivery Manager join a Lab chat? If not, the build plan changes instead and Story 4.1 reads differently.
  3. decision Start commit. May a claim record the commit the Story starts from? One value per claim.
